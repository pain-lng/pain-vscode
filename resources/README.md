# Extension Assets

## Icon

The extension requires a PNG icon at `resources/icon.png` (128x128 pixels recommended).

To create the icon from the SVG:
1. Open `icon.svg` in an image editor (Inkscape, GIMP, etc.)
2. Export as PNG at 128x128 pixels
3. Save as `icon.png` in this directory

Alternatively, you can use online tools like:
- https://cloudconvert.com/svg-to-png
- https://convertio.co/svg-png/

The icon should be:
- 128x128 pixels (minimum)
- Square aspect ratio
- PNG format
- Transparent background preferred
